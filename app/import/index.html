导入课程表

请选择方式

课程数据只在当前设备处理和保存。

电脑导入

  1. 点击“复制书签”。
  2. 在 Chrome 或 Edge 中新建书签。
  3. 将复制内容粘贴到书签网址。
  4. 打开学校教务系统个人课表。
  5. 点击“导入 AnyClass 课表”书签。

显示或隐藏书签栏：Ctrl + Shift + B

手机 / iPad 导入

添加一次快捷指令，以后即可从 Safari 分享菜单导入课表。

  1. 添加现有兼容的课表导入快捷指令。
  2. 在 Safari 登录学校教务系统。
  3. 打开个人课表并点击分享。
  4. 在分享菜单中运行课表导入快捷指令。
  5. 在打开的 AnyClass 页面选择生成的课表文件。
添加课表导入快捷指令

快捷指令目标：https://anyclass.heyaaron.asia/import/?method=file

隐私保护：课程数据只在当前设备处理，不会上传服务器。

Safari 出于安全限制仍会要求手动选择一次生成的文件，这是预期行为。

从文件导入课表

选择一份 AnyClass 课表 JSON 文件，校验通过后先预览，再由你确认保存。

文件只在此浏览器内读取，课程数据不会上传服务器。

支持的文件结构

{
  "schemaVersion": 1,
  "school": {"id": "school-id", "name": "学校名称"},
  "semester": {"academicYear": "2026-2027", "term": "1"},
  "meetings": []
}

同一学校、同一学期再次导入时，仅替换该学期记录，不会追加重复数据。

从剪贴板导入

粘贴 AnyClass JSON，校验通过后可预览并保存。课程数据只在本机处理。

也可以直接长按或使用快捷键粘贴。

AI 辅助：从课程表截图生成 JSON
  1. 截图课程表
  2. 复制下方课程表提示词
  3. 将截图和提示词发送给你选择的 AI
  4. 复制 AI 返回的 JSON
  5. 回到 AnyClass 粘贴并预览
  6. 核对后保存

AI 辅助导入目前仍处于实验阶段，可能误识别星期、节次、周次、地点等信息。请以原课表和导入预览为准，核对无误后再保存。AnyClass 不上传截图，也不调用 AI 服务。
