手机导入课表

添加一次快捷指令，以后在 Safari 的分享菜单中即可导入。

  1. 添加现有兼容的课表导入快捷指令。
  2. 在 Safari 登录学校教务系统。
  3. 打开个人课表并点击分享。
  4. 在分享菜单中选择课表导入快捷指令。
添加课表导入快捷指令

域名检查：安装或更新后，请确认快捷指令最后的“打开 URL”是 https://anyclass.heyaaron.asia/import-file/。如果仍为旧域，只修改这一项；不要改动已通过验证的解析脚本。

高级设置 / 手动安装

手动配置

  1. 打开“快捷指令”，新建快捷指令并命名为“导入 AnyClass 课表”。
  2. 开启“在共享表单中显示”。
  3. 点共享输入类型，取消其他类型，只保留“Safari 浏览器网页”。
  4. 添加“在网页上运行 JavaScript”动作，将动作输入绑定到“快捷指令输入”。
  5. 粘贴上方 Copy-safe 脚本，并将运行结果命名为 JSResult。

输入类型说明：不要选择“无”、当前 App、URL、文本或普通文件。JavaScript 动作必须在“快捷指令输入”上运行。

复制手动安装脚本

结果处理（防止空文件）

  1. 从 JSResult 获取 ok。
  2. 仅当 ok 为 true：读取 fileName、jsonText、meetingCount，将文本设为 jsonText，按 fileName 命名并保存文件，然后打开 https://anyclass.heyaaron.asia/import-file/。
  3. 如果 ok 不为 true：读取 errorCode 和 errorMessage，显示“导入失败”提醒并立即停止快捷指令。

失败分支禁止继续：不要读取或保存 fileName/jsonText，不要执行“存储文件”，也不要打开导入页。这样可以避免生成 0 KB 文件。

隐私保护：课程数据只在当前设备处理，不会上传服务器。

保存完成后，在自动打开的导入页选择刚生成的课表文件，预览并确认。由于 Safari 的安全限制，仍需手动选择一次文件，这是预期行为。
