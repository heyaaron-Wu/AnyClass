# Public Screenshot Plan

## Required captures

1. Today：正在上课或下一节课状态
2. Weekly Timetable：当前周课表
3. Import：统一导入入口
4. Settings：设置中心与节次配置
5. Light / Dark：同一合成课表的主题对比

## Sanitization gate

- 只使用合成课程名、教师名和教学楼。
- 不显示学校名称、学号、学生姓名、真实课程组合或内部 build/debug 信息。
- 截图前清理浏览器地址栏、通知、其他标签和本地文件路径。
- 390px、430px 和桌面分别检查溢出与 Dock 遮挡。

本候选只提供计划，不包含伪造或未验收截图。
