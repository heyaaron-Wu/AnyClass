# JSON 导入的可选上课时间

Schema 1 JSON 可在根对象增加可选的 `periodTimes` 对象。键为第 1–30 节的节次，值必须包含 24 小时制 `HH:mm` 格式的 `start` 和 `end`：

```json
{
  "periodTimes": {
    "1": {"start": "08:00", "end": "08:45"},
    "2": {"start": "08:55", "end": "09:40"}
  }
}
```

此片段只展示可选字段；实际导入文件仍须包含 `schemaVersion`、`school`、`semester` 和 `meetings`。

- 未提供 `periodTimes` 时，使用 AnyClass 默认作息，不表示学校提供了这些时间。
- 只提供部分节次时，缺失节次由 AnyClass 默认作息补全；预览会逐节标出来源。超出默认作息范围的缺失节次不会编造时间。
- 所有已提供时间及补全后的有效时间必须按节次顺序排列，不得倒置或重叠。无效时间会拒绝导入，不会静默替换为默认值。
- 预览中用户确认的修改优先于 JSON 时间。重导入若会改变已有课表时间，须明确选择保留已有时间或采用本次时间；仅含默认时间的重导入继续自动保留已有时间。
- 保存前请核对学校实际作息。此字段不改变数据库版本，也不直接写入系统日历；ICS 导出使用最终保存的有效时间。
