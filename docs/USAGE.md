# 使用说明

## 快速开始

1. 打开 [AnyClass](https://anyclass.heyaaron.asia/)。
2. 首次使用时创建或选择一个课表。
3. 从“导入”选择适合当前设备和数据来源的方式。
4. 导入内容会先进入统一预览（Unified Preview）。
5. 确认课表目标、学校名称、学期等必要信息后保存。
6. 在“今天”和“课表”查看课程。

## 导入

AnyClass v0.2.0 的通用导入遵循以下规则：

- 当前选中的课表是默认导入目标。
- 来源信息只用于提示，不会自动把课程静默导入其他课表。
- 通用导入不会为了通过校验而伪造学校 ID。
- 缺失学校名称等必要信息时，会在保存前要求确认或补充。
- AI 辅助导入只整理为 AnyClass Course 数据，不直接创建系统日历事件。
- 文件、剪贴板、AI 辅助和支持的 Bookmark / Shortcut 流程会进入统一预览后再保存。

## 多课表

可以在本地维护多个课表，并切换当前课表。

切换后：

- “今天”和“课表”应显示当前课表的数据。
- 新的通用导入默认写入当前选中的课表。
- 可以在本地数据相关页面继续编辑课表名称和学校名称。

## Apple 日历 / ICS

AnyClass 当前支持 **ICS 导出**，不提供 ICS 文件反向导入到 AnyClass。

需要日历文件时，在 AnyClass 中使用导出功能生成 ICS，再交给系统日历处理。

在 iPhone 或 iPad 上，可使用系统提供的日历导入流程完成添加。

## 数据保存

AnyClass 采用 Local-first 设计：

- 课表数据默认保存在当前设备浏览器中。
- 清除浏览器站点数据、使用无痕模式或更换设备可能导致本地课表不可用。
- 在执行浏览器清理或设备迁移前，建议先保留需要的导出文件。
